# Nexellence Summer Institute — Course Materials

This repository contains the teaching materials for the Nexellence Summer Institute. It is organized to make it easy to find slides, code, data, and exercises for each session.

## Repository Structure

```
.
├── slides/        # Lecture slides and presentations
├── code/          # R and Stata scripts used in lectures and exercises
├── data/          # Datasets used in the course
└── exercises/     # Problem sets and in-class exercises
```

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/hhadah/nexellence-summer-instit.git
   ```
2. Navigate to the relevant session folder inside `slides/`, `code/`, or `exercises/`.
3. Data files are stored in `data/`. Large raw data files may be excluded from the repository; see the notes in `data/README.md` if present.

## Software

The course materials use:
- **R** (with R Markdown / Quarto for slides and exercises)
- **Stata** (selected code examples)
- **LaTeX** (for any typeset handouts)
